One pickup line, as if a vending machine were flirting with a passing
human, for One Line, One Minute: The Vending Machine Pickup Line
Contest on make.fun. The machine has watched the human press its
buttons every single day without once asking its name — it's B4 — and
it has been saving the last chocolate bar for them. The line is spoken
by the machine itself, in its own world of buttons, slot codes and
snacks; it is charming rather than creepy (a quiet gift held back for
one person), and the twist lands at the end, so the line is short,
speakable, and stands alone — exactly what the brief asks for.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (UTF-8, 1–200 characters).
